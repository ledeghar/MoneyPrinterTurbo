# MN Short — Remotion editorial graphics / 10 languages

This is a **second, review-only compositor**. The original MoneyPrinterTurbo
and Pexels-based pipeline is not changed. It makes one source-grounded
editorial into ten MP4 renders using one visual storyboard.

Each language has its own narration and audio-derived scene timing. Arabic is
rendered right-to-left; Chinese, Japanese and Arabic require Noto fonts in the
runner. Output size: **1080 x 1920** (9:16), 30 fps.

## GitHub Actions

Use the workflow **MN Short - Motion graphics in 10 languages (review only)**.
It offers:

- **demo**: A clearly disclosed non-news demonstration about how news visuals
  are verified, with translations for all ten languages. Needs no Gemini key.
- **live**: Runs existing RSS selector + Gemini journalist, creates one canonical
  Spanish narrative, translates each exact sentence into nine languages, and
  composes ten versions with the same scene/visual sequence. Requires existing
  secret GEMINI_API_KEY. This is **editorial draft only**.

The workflow first produces an assets/credit manifest and synthesized audio.
Then ten GitHub Actions workers render ten MP4 files in parallel, one per
language. Download the individual files under the run's **Artifacts** section.
Artifacts expire after three days. No social upload occurs.

## Important editorial limitations

- In the prototype, **Wikimedia Commons** is the only automatic photo source
  (CC0, public domain or CC BY selected from metadata). No source search hit is
  by itself proof of a person's visual identity. Images and credits require a
  final human check before reuse or publication. If no candidate is found,
  the named person's card is displayed without a photo: no impostor footage.
- **DDGS research** in the existing pipeline is for sourcing ideas, not an
  automatic license to embed downloaded photographs.
- **Geographical scenes** use explanatory schematic circles explicitly
  labelled as **not real maps**; do not depict fabricated geography.
- Word-level colored text is currently **paced within each audio segment**;
  sentence-to-scene sync is precise, but actual word-boundary sync is not yet
  implemented. This is why manual editorial/visual review is mandatory.
- Automated translation can mistranslate names, allegations, figures or
  qualifications. Check before publication, particularly Arabic, Chinese and
  Japanese, and before localizing titles/descriptions.
- Live news posts are not generated by the demo mode. No automatic uploads,
  schedules or monetization claims are attached to this compositor.
- Remotion has special licensing terms; this project was prepared for a
  solo-user pilot. Reassess eligibility if the production team grows.

    python scripts/mn_short_motion.py --mode demo
    cd mn-short-motion && npm install

Spanish, English, French, German, Italian, Portuguese, Russian, Chinese,
Japanese and Arabic have their own props JSON and MP3 files created by
the shared preparation step. Production should use the cloud Actions flow.


## Exact subtitle timing and mandatory authentic images (November 2026)

The earlier pilot evenly distributed highlighted words through each sentence.
This was not synchronized to the actual spoken voice. We now record Edge TTS
**WordBoundary** events from the same audio stream and send each word's actual
start/end timestamps to Remotion. Every language is measured individually.
If the synthesizer cannot return boundaries, generation stops rather than
claiming to have synchronized subtitles.

When a real person is named in the visual storyboard, image selection checks:
1. A name-matched Wikidata entity and curated P18 photo (if available);
2. Wikimedia Commons expanded named-photo search;
3. Exact file identity/source metadata, reuse license (PD/CC0/CC BY), creator
   attribution and the original Commons file page.

A missing or uncleared person's photograph now **fails the review render**.
It never substitutes initials, anonymous executives, stock imagery or a logo.
Wikidata/Commons evidence cannot fully replace visual/editorial identity review.

## One MP4 with ten selectable audio and subtitle tracks

The GitHub Actions **multilingual-master** job renders a subtitle-free common
video timeline and packages:

- MNShort_MASTER_10_AUDIO_10_SUBTITLES.mp4 — one 1080x1920
  H.264 master with ten selectable AAC voice tracks and ten selectable mov_text
  subtitle streams, with ISO language codes.
- YT_DUB_es.m4a, YT_DUB_en.m4a, ... YT_DUB_ar.m4a — audio-only tracks
  for the YouTube Studio multilang dubbing workflow.
- SUBTITULOS_es.srt, ... SUBTITULOS_ar.srt — separate language-specific
  caption files, for YouTube Studio or another editing tool.

To preserve natural voice rate, the common scene boundaries are determined
by the longest translated utterance in each scene, and shorter voices are
padded with silence. The universal master does not burn Spanish voice captions
into pixels: users select the matching embedded subtitles in a compatible
media player. Ten separate fully localized social cuts remain available.

**YouTube caveat:** Adding ten audio streams to the MP4 is not equivalent to
installing ten dubbed audio tracks on YouTube. For an eligible creator,
YouTube Studio > Languages > [video] > Add Language > Dub > Add is the
supported workflow. YouTube may not import extra MP4 audio streams as
user-selectable tracks. Eligibility depends on channel features.
